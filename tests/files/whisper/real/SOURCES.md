# Sources

No permissively licensed project ships Whisper JSON output with neutral text. So every file here is written for this repository in the exact shape that the tool writes. The text is new neutral sample text.

| File | Source | License |
|:--- |:--- |:--- |
| `openai_whisper_word_timestamps.json` | Written for this repository in the shape of openai-whisper `--output_format json --word_timestamps True`: `json.dump()` in [`WriteJSON`](https://github.com/openai/whisper/blob/86098128c0b4f24f0e2aa2994de830614b474227/whisper/utils.py), the segment fields of [`new_segment()`](https://github.com/openai/whisper/blob/86098128c0b4f24f0e2aa2994de830614b474227/whisper/transcribe.py) and the word fields of [`add_word_timestamps()`](https://github.com/openai/whisper/blob/86098128c0b4f24f0e2aa2994de830614b474227/whisper/timing.py). ASCII escapes such as `é`, and a cleared segment with empty text | MIT |
| `openai_whisper_german.json` | Written for this repository in the shape of openai-whisper `--output_format json --language de`, same sources. No `words` key except on the cleared segment, and an end time of `13.120000000000001` | MIT |
| `openai_api_verbose_json_words.json` | Written for this repository in the shape of the OpenAI API response for `response_format=verbose_json` with `timestamp_granularities[]=word` and `segment`: [API reference](https://platform.openai.com/docs/api-reference/audio/createTranscription), [`TranscriptionVerbose`](https://github.com/openai/openai-python/blob/e5de2e5656fb3d4fa70f050195382e6a4d59f806/src/openai/types/audio/transcription_verbose.py), [`TranscriptionSegment`](https://github.com/openai/openai-python/blob/e5de2e5656fb3d4fa70f050195382e6a4d59f806/src/openai/types/audio/transcription_segment.py) and [`TranscriptionWord`](https://github.com/openai/openai-python/blob/e5de2e5656fb3d4fa70f050195382e6a4d59f806/src/openai/types/audio/transcription_word.py). The text is the example of issue #83. Times are 32-bit floats such as `3.319999933242798` | MIT |
| `openai_api_verbose_json_french.json` | Written for this repository in the shape of the same API response with segments only, language `french`, and a last segment of one space | MIT |
| `faster_whisper_ctranslate2_words.json` | Written for this repository in the shape of whisper-ctranslate2 `--output_format json --word_timestamps True`, which runs faster-whisper: [`transcribe.py`](https://github.com/Softcatala/whisper-ctranslate2/blob/7c06913255bea6f630b6d1357e99dc0c3bfa1819/src/whisper_ctranslate2/transcribe.py), [`writers.py`](https://github.com/Softcatala/whisper-ctranslate2/blob/7c06913255bea6f630b6d1357e99dc0c3bfa1819/src/whisper_ctranslate2/writers.py) and the `Segment` and `Word` classes of [faster-whisper](https://github.com/SYSTRAN/faster-whisper/blob/7b99be5376b41cd481dfc52e8caa00a497c3294e/faster_whisper/transcribe.py) | MIT |
| `faster_whisper_ctranslate2_segments.json` | Written for this repository in the shape of whisper-ctranslate2 `--output_format json` without word timestamps, so `"words": null`. Same sources | MIT |
| `whisperx_diarize.json` | Written for this repository in the shape of WhisperX `--diarize --output_format json`: [`utils.py`](https://github.com/m-bain/whisperX/blob/771b4a14a9486f8fd5aef18ef49e35d639523dd3/whisperx/utils.py), [`alignment.py`](https://github.com/m-bain/whisperX/blob/771b4a14a9486f8fd5aef18ef49e35d639523dd3/whisperx/alignment.py) and [`diarize.py`](https://github.com/m-bain/whisperX/blob/771b4a14a9486f8fd5aef18ef49e35d639523dd3/whisperx/diarize.py). The word `15.` has no alignable character, so it has no times and no score | MIT |
| `whisper_cpp_oj.json` | Written for this repository in the shape of whisper.cpp `-oj`: `output_json()` in [`cli.cpp`](https://github.com/ggml-org/whisper.cpp/blob/60c0be6ac8fa71b1a2ae2dd938a31a34a508e774/examples/cli/cli.cpp). Tab indentation, offsets in milliseconds | MIT |
| `whisper_cpp_ojf.json` | Written for this repository in the shape of whisper.cpp `-ojf`, same source. Tokens with the special tokens `[_BEG_]` and `[_TT_n]` of [`whisper.cpp`](https://github.com/ggml-org/whisper.cpp/blob/60c0be6ac8fa71b1a2ae2dd938a31a34a508e774/src/whisper.cpp), and a word of two tokens | MIT |
| `whisper_cpp_ojf_split_utf8.json` | Written for this repository in the shape of whisper.cpp `-ojf` before the fix for [issue #1798](https://github.com/ggml-org/whisper.cpp/issues/1798). The first character is split across two tokens, so the token texts hold invalid UTF-8 | MIT |
| `expected/*.json` | Generated for this repository. Expected parse result of the file with the same name, written by `tests/files/generate-read-goldens.php` | MIT |
| `expected/*.out.json` | Generated for this repository. Expected output of the file with the same name, read and written as Whisper JSON by `tests/files/generate-write-goldens.php` | MIT |
